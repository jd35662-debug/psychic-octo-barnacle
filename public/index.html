    Tutorial

    How to use your home internet

    1. Start the server: run npm start on the home server computer.
    2. Find its LAN address: use your router page or your computer network settings to find an address like 192.168.1.25.
    3. Open it everywhere: on each home computer, tablet, or phone, visit http://LAN-IP:8080.
    4. Set it as the browser home page: bookmark the home page so everyone sees the same list of local sites.
    5. Add more sites: use Site Maker below to add custom local links such as a printer page, NAS folder, camera page, or game server.
